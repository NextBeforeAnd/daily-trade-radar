# 独立 CLI 模式

Daily Trade Radar 同时是 Codex Skill 和标准 Python CLI。CLI 可以独立安装和运行，但必须正确理解它的能力边界。

## 可以独立完成

- 根据配置生成可审计研究计划；
- 构建平台注册表驱动的采集清单；
- 有边界地采集公开 HTTP、RSS、Atom 和 Sitemap；
- 记录访问回执、快照和来源健康状态；
- 校验事件结构、日期、评分和覆盖账本；
- 对当前报告和上一期报告进行确定性去重；
- 生成中文或英文 Markdown、DOCX；
- 管理本地历史库、评测数据和可选快照后端。

## 不能独立保证

- 自动找到互联网上所有相关政策；
- 穿过登录、验证码、反爬或访问控制；
- 理解政策正文并可靠判断业务适用性；
- 替代法律、税务、海关或制裁专业人员；
- 无人值守地把抓取页面直接变成可发布结论。

## 推荐集成方式

外部研究系统、人工研究员或其他 Agent 负责生成符合输出架构的 `reviewed-events.json`，CLI 负责后续确定性处理：

```text
外部研究/人工核验
        ↓
reviewed-events.json
        ↓
validate → deduplicate → score check → render → alert preview
```

公开采集回执只能证明某个 URL 被尝试访问，不能证明页面已被实质阅读，也不能证明“没有政策更新”。

## 自动化建议

- 可以定时执行来源健康检查、公开页面快照和报告渲染；
- 不要在缺少人工复核的情况下自动发送高风险告警；
- 登录页面应使用操作者自己的只读浏览器会话，认证正文不得进入公共缓存；
- 将 `research_required` 和 `language_review_required` 视为正常的人机交接状态。
